## 2. 直接相关文献

### 2.1 Accelerating Deep Neural Networks on Mobile Multicore NPUs

- **年份/出处**：2023，CGO（21st ACM/IEEE International Symposium on Code Generation and Optimization）
- **作者**：Hanwoong Jung, Hexiang Ji, Alexey Pushchin, Maxim Ostapenko 等
- **DOI**：[10.1145/3579990.3580015](https://doi.org/10.1145/3579990.3580015)
- **论文讲了什么**：移动 SoC 中集成多个 NPU 核心后，主要并行方式是把 DNN 层切成多个子层。论文同时研究切分方向、子层执行顺序、同步和全局内存访问，并在单核内部使用流水执行。作者指出，局部存储通常只能容纳一层的输入、输出和权重，因此中间张量的全局内存访问及同步会成为瓶颈。
- **与赛题对应**：最接近场景 A 的“切图—分核—同步—DDR 搬运”联合优化，也可用于解释为什么只按算子数均分是不够的。
- **可借鉴方法**：切分方向选择、流水化、同步开销建模、全局内存访问优化。
- **边界**：论文主要围绕 DNN 层/子层，赛题要求对一般算子—张量 DAG 和官方核内评估流程进行优化。

### 2.2 Layer-Puzzle: Allocating and Scheduling Multi-task on Multi-core NPUs by Using Layer Heterogeneity

- **年份/出处**：2023，DATE（Design, Automation & Test in Europe Conference）
- **作者**：Chengsi Gao, Ying Wang, Cheng Liu, Mengdi Wang, Weiwei Chen, Yinhe Han, Lei Zhang
- **DOI**：[10.23919/DATE56975.2023.10137320](https://doi.org/10.23919/date56975.2023.10137320)
- **论文讲了什么**：提出 Layer-Puzzle 多任务分配与调度框架。方法包括延迟预测模型、动态并行化方案以及 QoS 感知的在线调度。它根据硬件资源和流量拥塞水平，为每层选择合适的并行版本，并从已编译的候选协同执行任务中选择更优组合。
- **与赛题对应**：对应赛题中的代理时间估计、资源负载均衡、候选方案筛选和关键任务优先。
- **可借鉴方法**：使用硬件资源和拥塞程度修正任务代价；保留多种编译候选，运行时选择更优版本；用 QoS/关键路径对任务排序。
- **论文摘要中的结果**：在 MLPerf 实验中，作者报告 ANTT、STP 和处理单元利用率分别最高约提升 1.61×、1.53×、1.95×。

### 2.3 Flexer: Out-of-Order Scheduling for Multi-NPUs

- **年份/出处**：2023，CGO
- **作者**：Hyemi Min, Jungyoon Kwon, Bernhard Egger
- **DOI**：[10.1145/3579990.3580025](https://doi.org/10.1145/3579990.3580025)
- **论文讲了什么**：针对多 NPU 共享缓存和内存的系统，提出 Flexer 乱序调度器。它使用列表调度动态安排 tiled workload，并在不同层级内存中跟踪数据 tile 的可用性，以增加指令级并行和数据复用。
- **论文结果**：在 2—4 核多 NPU 上，单层任务最高约 2.2× 加速，数据传输量约降低到原来的 1/1.2。
- **与赛题对应**：直接对应场景 B 的同核缓存复用、子图执行顺序以及问题 3 的共享 Cache 命中。
- **可借鉴方法**：允许就绪任务乱序发射；优先选择已经驻留片上缓存的数据；将数据可用性加入列表调度优先级。
- **边界**：论文偏向 tiled layer workload；赛题还存在 Task 边界、跨核固定等待、L1/UB 换入换出和共享 DDR 公平带宽模拟。

### 2.4 Tensor Slicing and Optimization for Multicore NPUs

- **年份/出处**：Journal of Parallel and Distributed Computing，第 175 卷（正式卷期为 2023；online-first DOI 时间为 2022-12-28）
- **作者**：Rafael Sousa, Marcio Pereira, Yongin Kwon, Taeho Kim, Namsoon Jung, Chang Soo Kim, Michael Frank, Guido Araujo
- **DOI**：[10.1016/j.jpdc.2022.12.008](https://doi.org/10.1016/j.jpdc.2022.12.008)
- **论文讲了什么**：提出 Tensor Slicing Optimization（TSO），通过张量切分、切分方向选择、执行顺序、同步和全局内存访问优化多核 NPU 上的 CNN 执行。核心目标是增加多核并行度，同时控制切分后中间张量的存储和搬运代价。
- **与赛题对应**：与“子图边界增加 COPY、并行度和通信开销权衡、核内流水”高度相似。
- **可借鉴方法**：沿张量访问关系选择切点；将切分后的中间数据传输显式计入目标；联合考虑并行和片外存储。
- **年份说明**：如果论文综述严格限定“发表年”，建议写 JPDC vol.175（2023）；如果按 online-first 时间检索，应注明 2022 年底 online-first。

### 2.5 Aries: A DNN Inference Scheduling Framework for Multi-core Accelerators

- **年份/出处**：2024，International Conference on Computing, Networks and Internet of Things
- **作者**：Yunyi Xiang, Zheng Wu, Haidong Yao, Xiankui Xiong, Fan Yang 等
- **DOI**：[10.1145/3670105.3670136](https://doi.org/10.1145/3670105.3670136)
- **论文讲了什么**：针对多核加速器部署 DNN 时的 segmentation、mapping、scheduling 和 instruction compilation 搜索空间，提出 Aries 框架。方法采用张量并行、行为级硬件模型和遗传调度算法，在准确性能模型上搜索多核映射方案。
- **与赛题对应**：非常适合参考“快速代理模型筛选 + 精确行为模型核验 + 启发式搜索”的整体架构。
- **可借鉴方法**：遗传算法或其他群智能算法搜索核心分配与顺序；以行为级模拟器作为最终评分器；用张量并行减少搜索空间。
- **边界**：论文的硬件模型和评价指标不同，不能直接套用其性能数值。

### 2.6 Discovering Efficient Fused Layer Configurations for Executing Multi-Workloads on Multi-Core NPUs

- **年份/出处**：2024，DATE
- **作者**：Younghyun Lee, Hyejun Kim, Yongseung Yu, Myeongjin Cho, Jiwon Seo, Yongjun Park
- **DOI**：[10.23919/DATE58400.2024.10546719](https://doi.org/10.23919/date58400.2024.10546719)
- **论文讲了什么**：多层卷积融合可以减少片外访存，但融合后片上内存使用可能出现不平坦的峰值。论文把可能的部分融合调度组织成图，并搜索同时优化执行时间和片上峰值内存的路径，允许少量片外访问增加来换取更好的多工作负载吞吐。
- **论文结果**：报告片上内存使用降低约 39%，延迟增加约 13%；释放出的片上空间可用于并行运行其他工作负载。
- **与赛题对应**：对应场景 B 中“合并子图减少通信”和“过度合并导致 L1/UB 压力”的矛盾。
- **可借鉴方法**：把融合/合并候选建成状态图；把片上峰值内存作为和时间并列的约束或次目标；在合并收益和换入换出代价之间做搜索。

### 3.1 Hardware-aware Graph Partition for Mobile Inference Acceleration

- **年份/出处**：2025，Workshop Proceedings of the 54th International Conference on Parallel Processing

- **DOI**：[10.1145/3750720.3757284](https://doi.org/10.1145/3750720.3757284)
- **论文讲了什么**：先 profiling 模型算子在手机 CPU、GPU、DSP/专用加速器上的行为，再建立硬件感知代价模型，以图划分方式选择更快的执行后端。论文使用 TVM 和 Android NN API 构建端到端编译流程。
- **论文结果**：报告最高约 17.29× 的移动推理加速。
- **与赛题对应**：可支持 Problem 1/2 README 中的“代理成本模型”；赛题中应把算子计算时间、Pipe 负载、边界 Tensor 字节数、DDR 工作量和同步等待都放入代价模型。

### 3.2 SmartMem: Layout Transformation Elimination and Adaptation for Efficient DNN Execution on Mobile

- **年份/出处**：2024，ASPLOS 2024
- **作者**：Wei Niu, Md Musfiqur Rahman Sanim, Zhihao Shu, Jiexiong Guan, Xipeng Shen, Miao Yin 等
- **DOI**：[10.1145/3620666.3651384](https://doi.org/10.1145/3620666.3651384)
- **论文讲了什么**：Transformer、Stable Diffusion 和 LLM 等模型中，算子之间的 layout transformation 会造成显著开销。SmartMem 对算子分类，搜索生产者—消费者布局组合，尽量让多个相邻算子共享同一种张量布局，并设计适合移动设备 2.5D 内存的布局。
- **与赛题对应**：可用于扩展张量生命周期、片上驻留和搬运量模型，解释为什么相同的 DAG 划分在不同数据布局下会产生不同时间。
- **边界**：重点是布局变换消除，不是多核 Task 依赖调度本身。

### 3.3 HiDP: Hierarchical DNN Partitioning for Distributed Inference on Heterogeneous Edge Platforms

- **年份/出处**：2024，arXiv 预印本（arXiv:2411.16086）
- **作者**：Zain Taufique, Vyas, Aman, Antonio Miele, Pasi Liljeberg, Anil Kanduri
- **链接**：[arXiv:2411.16086](https://doi.org/10.48550/arxiv.2411.16086)
- **论文讲了什么**：针对异构边缘节点，先在全局设备层划分 DNN，再在节点内部按照核心级异构性进行局部划分，从而提高资源利用率。作者在商用边缘设备上比较了该分层策略和其他分布式推理方法。
- **论文结果**：摘要报告平均延迟降低 38%、能耗降低 46%、吞吐率提高 56%。
- **与赛题对应**：可借鉴“粗粒度子图分配—核心内部细化”的分层搜索思路。
- **边界**：原文是跨设备分布式推理；赛题是单个多核 NPU 平台，跨核通信和 DDR 带宽语义不同。

### 3.4 HopScotch: A Holistic Approach to Data Layout-Aware Mapping on NPUs for High-Performance DNN Inference

- **年份/出处**：2025，ACM Transactions on Architecture and Code Optimization
- **作者**：Suhong Lee, Boyeal Kim, Yongseok Choi, Hyuk-Jae Lee
- **DOI**：[10.1145/3711821](https://doi.org/10.1145/3711821)
- **论文讲了什么**：DNN 层的访问顺序和片上内存布局不匹配时，会插入 layout reorder 和 bubble cycles。HopScotch 从片上内存到 systolic array 的数据路由、可编程向量路径和数据布局映射整体优化 DNN 执行。
- **与赛题对应**：可作为“核内执行时间不能只用四条 Pipe 负载最大值估计”的硬件层解释，也可启发布局/搬运联合代价模型。
- **边界**：属于微架构和布局映射优化，直接用于赛题时需要接入官方 Step1/2/3 规则。

### 3.5 PyTorchSim: A Comprehensive, Fast, and Accurate NPU Simulation Framework

- **年份/出处**：2025，MICRO（58th IEEE/ACM International Symposium on Microarchitecture）
- **作者**：Won-Hyuk Yang, Yunseon Shin, Okkyun Woo, Geonwoo Park, Hyungkyu Ham, Jeehoon Kang
- **DOI**：[10.1145/3725843.3756045](https://doi.org/10.1145/3725843.3756045)
- **论文讲了什么**：提出支持多核、多模型租用、向量指令、编译器、推理/训练和数据相关时序的 NPU 模拟框架。它用 PyTorch 2 后端、MLIR/LLVM 编译、自定义 RISC-V 扩展和 gem5/Spike 建模，并提出 Tile-Level Simulation，在保持 DRAM 和互连周期级模拟的同时降低完整指令级模拟成本。
- **与赛题对应**：直接支持赛题中“代理估计—精确事件模拟”的两级方法，尤其是共享 DDR、互连和多核并发的验证思路。

### 3.6 A Hierarchical Dispatcher for Scheduling Multiple Deep Neural Networks (DNNs) on Edge Devices

- **年份/出处**：2025，Sensors
- **作者**：Hyung Kook Jun, Taeho Kim, Sang Cheol Kim, Young Ik Eom
- **DOI**：[10.3390/s25072243](https://doi.org/10.3390/s25072243)

## 6. 写论文时可以引用的概括句

1. **关于切图与搬运的权衡**：已有多核 NPU 研究表明，DNN 层或张量切分能够增加并行度，但会引入同步和全局内存访问开销，因此切分方向、执行顺序与片外数据搬运需要联合优化（Jung et al., 2023；Sousa et al., 2023）。
2. **关于缓存复用**：多 NPU 乱序调度研究显示，利用片上缓存中已有数据的可用性来决定任务发射顺序，可以在提高并行度的同时减少数据传输（Min et al., 2023）。
3. **关于硬件感知代价模型**：硬件感知图划分和算子级调度工作通常先通过 profiling 获得算子延迟，再用预测模型指导图划分或 DAG 调度（Yu et al., 2025；Kim et al., 2026）。
4. **关于片上容量约束**：多层融合可以降低边界访存，但融合后的片上峰值内存可能上升，因此调度目标应同时包含执行时间和片上存储峰值（Lee et al., 2024）。
5. **关于模拟与验证**：NPU 调度搜索需要快速代理模型减少候选数量，再通过行为级或周期级模拟器评估共享带宽、互连和多核并发造成的实际时间变化（Xiang et al., 2024；Yang et al., 2025）。

## 7. 使用时的注意事项

- 论文的实验硬件、网络模型和指标与赛题官方配置不同，不能直接引用论文中的加速比作为赛题结果。
- 赛题最终目标是字典序目标：先最小化 Makespan，再最小化新增 DDR 搬运量；大多数论文采用平均延迟、吞吐率、能耗或 QoS 目标，引用时需要说明差异。
- 对论文进行正式参考文献著录时，建议再根据学校格式补齐 DOI、会议全称、页码和作者完整列表。
- `Tensor Slicing and Optimization for Multicore NPUs` 的 DOI online-first 日期为 2022-12-28，但正式卷为 JPDC 175（2023）；若严格按 2023—2026 筛选，应在文献表中注明这一时间边界。
