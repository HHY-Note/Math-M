# 通用神经网络处理器下的多核调度问题：术语表格

本表与《题目分析报告.md》共用定义。数学符号置于标准数学定界符内；英文接口字段用代码格式，其下划线属于原接口，不是数学排版。单位统一为 bytes、cycles、bytes/cycle；不换算秒，不混用 bit 与 byte。

## 1. 全局符号

| 中文术语 | 英文术语 | 符号 | 定义 | 单位 | 首次出现位置（报告） | 禁止混用 |
|---|---|---|---|---|---|---|
| 原始计算图 | Computational graph | $G=(V,E)$ | 操作与张量构成的有向二部无环图 | 无量纲 | §5.1 | 不能等同操作商图或展开执行图 |
| 全部节点集 | Vertex set | $V$ | 操作与张量节点的并集 | 无量纲 | §5.1 | 节点不全是操作 |
| 边集 | Edge set | $E$ | 原始输入输出依赖关系 | 无量纲 | §5.1 | 边条数不等于字节量 |
| 操作节点集 | Operation set | $O$ | 包含计算和 COPY 的所有操作 | 无量纲 | §5.1 | 不同于操作类型字符串 |
| 张量节点集 | Tensor set | $T$ | 原图数据块集合 | 无量纲 | §5.1 | 不用作完成时间 |
| 搬运操作集 | Copy operation set | $O_{\mathrm{copy}}$ | 类型为 COPY_IN/COPY_OUT 的操作 | 无量纲 | §5.1 | 不参与子图映射决策 |
| 决策操作集 | Eligible operation set | $U$ | 去除原始 COPY 后的操作集合 | 无量纲 | §5.1 | 不包含 Tensor |
| 张量大小 | Tensor size | $s_t$ | 张量或驻留实例的字节大小 | bytes | §5.1 | 不等于边权或周期 |
| 计算周期 | Compute cycles | $c_o$ | 输入给定的核内计算操作耗时 | cycles | §5.1 | COPY cycles 不作真实 DDR 耗时 |
| 指定管道 | Assigned pipe | $p_o$ | 操作输入字段指定的 Pipe 类别 | 无量纲 | §5.1 | 不按操作名自行推断 |
| 核心数 | Number of cores | $N$ | 可用同构核心数 | 无量纲 | §5.1 | 不等于子图数 |
| 子图数 | Number of subgraphs | $K$ | 方案中实际使用的子图数量 | 无量纲 | §5.1 | B 中不等于 Task 数 |
| 调度方案 | Partition and schedule | $\theta$ | 分区、分核、同核次序的三元组 | 无量纲 | §5.1 | 不等于操作时间线 |
| 子图归属映射 | Partition map | $g$ | 每个决策操作唯一所属 sgid | 无量纲 | §5.1 | 不映射原 COPY |
| 核心分配映射 | Core assignment | $a$ | 每个子图唯一所属核心 | 无量纲 | §5.1 | 核心 ID 与 sgid 不同 |
| 同核子图次序 | Per-core subgraph order | $\pi_k$ | 核心 k 上的有序子图列表 | 无量纲 | §5.1 | 不是可任意指定的 Pipe 序列 |
| 固定参数集合 | Fixed configuration | $\eta$ | 容量、带宽、等待等 config 参数 | 复合，见各项 | §5.1 | 不作为自由优化变量 |
| 评估映射 | Evaluator mapping | $F_q$ | 问题 q 的原评估器完整输出映射 | 复合，见输出字段 | §5.1 | 不等于单个操作完成时刻 |
| 可行方案集合 | Feasible plan set | $\Omega_q$ | 通过图、映射、执行与容量校验的方案 | 无量纲 | §5.1 | 仅商图无环还不足够 |
| 总完成时间 | Makespan | $C_q(\theta)$ | 问题 q 中全部操作结束时刻最大值 | cycles | §5.1 | 非计算周期之和、非生成算法耗时 |
| 官方新增搬运 | Added copy volume | $D_q(\theta)$ | 评测器 scheduled 减 original 的字节数 | bytes | §5.1、§5.4 | 题三不等于物理 DDR 净流量 |
| 已调度搬运量 | Scheduled copy volume | $D_{\mathrm{sched},q}$ | 含重建边界和 Spill 的 COPY 字节 | bytes | §5.4 | 题三包含命中 Cache 的 COPY |
| 原图搬运量 | Original copy volume | $D_{\mathrm{orig}}$ | 原始图已有 COPY 的字节基准 | bytes | §5.4 | 非单核含 Spill 的全部搬运 |
| 私有存储容量 | Private memory capacity | $M_m$ | 类型 m 为 L1 或 UB 的每核容量 | bytes | §5.2 | L1/UB 不相互借用 |
| DDR 总带宽 | Aggregate DDR bandwidth | $B_{\mathrm{D}}$ | 全核读写共享的 60 bytes/cycle | bytes/cycle | §5.2 | 不是每核带宽 |
| A 同核等待 | Same-core Task delay | $\delta_{\mathrm{A},s}$ | 前一同核 Task 完成后的 100 cycles | cycles | §5.2 | 不给所有依赖重复累加 |
| A 跨核等待 | Cross-core Task delay | $\delta_{\mathrm{A},c}$ | 跨核前驱 Task 完成后的 1,000 cycles | cycles | §5.2 | 不同于 B 的 500 cycles |
| B 同步延迟 | Cross-core copy release delay | $\delta_{\mathrm{B}}$ | COPY_OUT 后至 COPY_IN 可释放的 500 cycles | cycles | §5.2 | 不占 Pipe 和带宽 |
| L2 容量 | Shared Cache capacity | $M_{\mathrm{C}}$ | FIFO Cache 1,048,576 bytes | bytes | §5.2 | 不按十进制 MB 替换 |
| Cache 总读带宽 | Cache read bandwidth | $B_{\mathrm{C}}$ | Cache 命中读共享 250 bytes/cycle | bytes/cycle | §5.2 | 不与 DDR 带宽合并或扣减 |
| 子图商图 | Quotient graph | $Q(\theta)$ | 每个子图缩并为节点后的依赖图 | 无量纲 | §5.3 | 不等于按核心缩并的图 |
| 开始/完成时刻 | Start/finish time | $S_o,F_o$ | 展开操作 o 的实际起止时刻 | cycles | §5.3 | 下标为 Task 时特指 Task 完成 |
| 驻留实例集合 | Resident tensor instances | $\mathcal{R}_{k,m}(\tau)$ | 时刻 τ、核心 k、类型 m 的物理驻留实例 | 无量纲 | §5.3 | 逻辑同一张量可有不同版本 |
| 活跃搬运数 | Active transfer count | $n_P(\tau)$ | 带宽池 P 中在途搬运的数量 | 无量纲 | §5.4 | 不等于核心数 |
| 带宽池容量 | Bandwidth-pool capacity | $B_P$ | DDR 或 Cache 池的总带宽 | bytes/cycle | §5.4 | 不同池独立 |
| 剩余工作量 | Remaining bytes | $r_j$ | 搬运 j 尚未完成的字节量 | bytes | §5.4 | 代码 remaining_work 可用满带宽周期表示 |
| Task 激活时刻 | Task activation time | $A_b$ | Task b 满足前序与等待约束的激活时刻 | cycles | §6.1 | 不必等于其中首个计算开始时刻 |
| 计算优先级 | Compute critical-path rank | $h(o)$ | 从操作 o 到计算终点的最长计算周期和 | cycles | §6.2 | 不是实际含通信关键路径 |
| 内存占用面积 | Memory occupancy integral | $H(\theta)$ | 各核各类驻留字节随时间的积分和 | bytes·cycle | §7.2 | 不等于峰值或硬约束 |
| FIFO 状态 | FIFO Cache state | $\mathcal{Q}(\tau)$ | 按插入次序存放逻辑张量键的队列 | 无量纲 | §8.1 | 与商图 Q 不同，使用花体区分 |
| 命中/未命中字节 | Hit/miss bytes | $D_{\mathrm{hit}},D_{\mathrm{miss}}$ | 可缓存 COPY_IN 的命中/未命中字节累计 | bytes | §8.1 | 不包括所有 COPY_OUT |
| 字节命中率 | Byte-weighted hit rate | $\rho$ | 命中字节除以全部可缓存访问字节 | 无量纲 | §8.1 | 不等于次数命中率 |
| 单核基准时间 | Single-core baseline makespan | $C_{\mathrm{single},i}$ | 用例 i 整图单核原评估结果 | cycles | §9.1 | 不用任意单核优化方案作分母 |
| 多核加速比 | Multicore speedup | $S_{q,i}(N)$ | 单核基准除以问题 q 的 N 核时间 | 无量纲 | §9.1 | 不同于 L2 相对收益 |
| 平均加速比 | Mean case-wise speedup | $\overline{S}_q(N)$ | 100 个逐例比值的算术平均 | 无量纲 | §9.1 | 不等于总时间比 |
| L2 相对加速比 | Cache speedup at fixed core count | $R_i(N)$ | 相同核数无 L2 时间除以有 L2 时间 | 无量纲 | §9.1 | 需注明固定方案还是分别优化 |
| 计算 Pipe 总负载 | Aggregate compute-pipe work | $W_{\mathrm{M}},W_{\mathrm{V}}$ | 原图在对应计算 Pipe 的周期总和 | cycles | §9.2 | 不把 M/V 负载串行相加成完成时间 |
| 纯计算关键路径 | Compute-only critical path | $L_{\mathrm{comp}}$ | 原计算依赖中计算周期最长路径 | cycles | §9.2 | 用作下界，不当真实时间 |
| 完整评测次数 | Full evaluation count | $J$ | 搜索中调用完整评估器的次数 | 无量纲 | §10 | 不等于搜索轮数 |
| 一次评测开销 | Evaluation runtime | $T_{\mathrm{eval}}$ | 核内展开及多核模拟的实际运行耗时 | seconds | §10 | 非模拟时钟周期 |

求和中的 i、j，操作 o、张量 t、子图 b、核心 k、存储类别 m、问题 q、时间 τ 为局部索引或对象标记，其取值在邻近公式中说明；不再另建同义符号。

## 2. 专业术语与接口

| 中文术语 | 英文术语 | 符号/接口 | 定义 | 单位 | 首次出现位置（报告） | 禁止混用 |
|---|---|---|---|---|---|---|
| 神经网络处理器 | Neural Processing Unit | NPU | 题设同构多核计算平台 | 无量纲 | §1 | 不泛化为异构 CPU/GPU 平台 |
| 有向无环图 | Directed Acyclic Graph | DAG | 有向依赖中不存在环 | 无量纲 | §1 | 原图无环不保证商图无环 |
| 张量超边 | Tensor hyperedge | — | 一个生产者及全部消费者的共享数据关系 | 无量纲 | §4.2 | 不把高扇出拆成独立重复数据 |
| 子图 | Subgraph | sgid | 参赛方案划分的计算节点集合 | 无量纲 | §3 | 不恒等于 Task |
| 执行任务 | Execution task | Task | 一次下发到一个核心的执行单元 | 无量纲 | §1、§3 | A 一子图一 Task；B 一核一 Task |
| 核外主存 | Double Data Rate memory | DDR | 全核心共享的主存与带宽池 | bytes | §1 | 不等同私有 L1/UB |
| 统一缓冲区 | Unified Buffer | UB | 每核私有、按 pos 字段认定的片上存储 | bytes | §3 | 不与 L1 容量合并 |
| 矩阵计算管道 | Cube compute pipe | `PIPE_M` | 题设矩阵计算单元管道 | 无量纲 | §4.1 | 操作种类和管道字段分开 |
| 向量计算管道 | Vector compute pipe | `PIPE_V` | 题设向量计算单元管道 | 无量纲 | §4.1 | 与 PIPE_M 可并行但受依赖约束 |
| 搬入/搬出管道 | Memory transfer pipe | `PIPE_MTE2` / `PIPE_MTE3` | 各核独立单执行器的搬运管道 | 无量纲 | §5.2 | 管道并发不代表独享 DDR |
| 搬入/搬出操作 | Copy in/out | `COPY_IN` / `COPY_OUT` | 评估器构建与处理的数据搬运操作 | bytes、cycles 分别记录 | §3 | 不作为 node_to_subgraph 的键 |
| 换出换入 | Spill / reload | Spill | 容量不足时自动生成的额外数据搬运 | bytes | §1 | 不保证每次都要写回，可能已有 backing |
| 持久后备副本 | Backing storage copy | backing | 可供后续换入复用的 DDR 副本 | bytes | §2.3、§5.3 | 不等于当前片上驻留实例 |
| 写后读/读后写/写后写约束 | RAW / WAR / WAW dependency | RAW/WAR/WAW | 数据依赖与存储复用需保留的时序关系 | 无量纲 | §1、§2.3 | 不只检查原始 RAW |
| 先进先出缓存 | First-In First-Out Cache | FIFO Cache | 按插入顺序淘汰，命中查询不刷新；命中读在途被淘汰后，完成可重新插入 | 无量纲 | §1、§8.1 | 不等于 LRU；不得遗漏完成事件 |
| 最近最少使用 | Least Recently Used | LRU | 命中会改变最近使用顺序的另一策略 | 无量纲 | §8.2 | 本题未采用，不得替换 FIFO |
| 未来最远使用替换 | Farthest-next-use replacement | Belady-style | 核内 Spill 候选中选择下一次使用最晚者 | 无量纲 | §2.3 | 不宣称本题全局最优 |
| 执行死锁/等待环 | Execution deadlock / wait cycle | — | FIFO、数据、内存或跨核关系造成的循环等待 | 无量纲 | §1 | 商图无环不足以排除 |
| 离散事件模拟 | Discrete-event simulation | — | 在完成、释放等时刻推进模拟状态 | cycles | §3 | 不采用固定步长拟合替代评分 |
| 子图映射字段 | Node-to-subgraph map | `node_to_subgraph` | 十进制字符串 op ID 到非负整数 sgid | 无量纲 | §3 | 仅覆盖非 COPY 操作 |
| 核心调度字段 | Core schedules | `core_schedules` | 每核按顺序列 sgid 的二维数组 | 无量纲 | §3 | 不是每核计算节点 ID 列表 |
| 官方搬运字段 | Evaluator movement fields | `data_movement_bytes` | 原始、已调度、新增及分项搬运记录 | bytes | §2.3 | 题三不可直接当物理 DDR 流量 |
| 实际内存路径 | Actual memory path | `memory_path` | 该搬运实际走 DDR 还是 Cache | 无量纲 | §5.4 | 与原张量 pos 不同 |
| 缓存身份键 | Logical tensor identity | `logical_tid` | Cache 查询使用的逻辑键，由展开实现产生 | 无量纲 | §8.1 | 不把新物理 ID 默认等同旧逻辑键 |
| 格式示例生成器 | Interface stub | `stub_multicore_cut_and_schedule.py` | 用于演示方案格式与校验 | 无量纲 | §2.1、§6.3 | 不作为唯一性能基线 |

## 3. 表述规范

“加速比 1.2”指旧耗时/新耗时为 1.2，不写成“减少 20% 耗时”；对应耗时降低为约 16.7%。本表的示例仅解释术语，并非本题计算结果。

“平均”“峰值”“总量”必须指明用例、核数、场景及分母；“最优”仅在有证据的范围内使用，启发式输出称“当前最好可行解”。题一、题二单核曲线点按题面为 1，题三相对 Cache 加速比不得机械设为 1。
